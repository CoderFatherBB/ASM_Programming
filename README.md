## About

This repository is a practical archive of 8086 Assembly Language Programming work. It contains solved answer files, proper runnable programs, question sets, and the DOS-era tools needed to assemble and link many of the examples.

## Repository Map

- `Answers/`: numbered assembly solutions.
- `Proper_Programs/`: named programs for arithmetic, conversion, character printing, grading, and sign counting.
- `Ouestions/`: question prompts and basic problem statements.
- `IMP_Softwares_To_Run_ASM_Programs/`: utilities such as `TASM`, `TLINK`, and `edit.com`.


## Getting Started

Clone the repository:

```bash
git clone https://github.com/CoderFatherBB/ASM_Programming.git
cd ASM_Programming
```

Open the folder or notebook you want to explore. Most directories are self-contained, so start from the local `README.md`, source file, notebook, or project folder for that topic.
